## Пошаговая инструкция по созданию приложения «GitHub User Finder»

### 1. Поле ввода для поиска пользователя GitHub
- В интерфейсе разместите текстовое поле (`Entry` в Tkinter, `QLineEdit` в PyQt или аналогичное в другой библиотеке).
- Добавьте кнопку «Поиск» рядом с полем.
- При нажатии на кнопку считывайте введённый логин пользователя.

### 2. Отображение результатов поиска
- После отправки запроса к GitHub API (например, `https://api.github.com/users/{username}`) отображайте найденные данные:
  - Аватар.
  - Имя пользователя.
  - Количество репозиториев, подписчиков и т. д.
- Используйте список (`Listbox`, `QListWidget` или таблица) для вывода нескольких пользователей, если поиск поддерживает автодополнение.

### 3. Добавление пользователей в избранное
- Для каждого найденного пользователя добавьте кнопку «Добавить в избранное».
- При нажатии сохраняйте данные пользователя (логин, имя, аватар и т. д.) в отдельный список избранных.

### 4. Сохранение избранных пользователей в JSON
- Используйте модуль `json` для работы с файлом избранных:
  - При добавлении пользователя — обновляйте JSON-файл.
  - При запуске приложения — загружайте избранных из файла.
- Пример структуры JSON:
```json
[
    {"login": "user1", "name": "User One", "avatar_url": "https://..."},
    {"login": "user2", "name": "User Two", "avatar_url": "https://..."}
]
```

### 5. Проверка корректности ввода
- Перед отправкой запроса проверяйте, что поле поиска не пустое.
- Если поле пустое — выводите предупреждение пользователю.

### 6. Использование Git
- Создайте локальный репозиторий: `git init`.
- Добавьте файлы проекта, исключите временные и системные файлы через `.gitignore` (например, для Python: `__pycache__/`, `.env`, `.vscode/`).
- Регулярно фиксируйте изменения: `git add .`, `git commit -m "Описание"`.
- Опубликуйте репозиторий на GitHub/GitLab/Bitbucket.

### 7. Написание README
Создайте файл `README.md` (или .txt/.docx) с такой структурой:

```
# GitHub User Finder

## Автор
Иванов Иван

## Описание
Приложение для поиска пользователей GitHub с возможностью добавления их в избранное и сохранения списка в JSON.

## Использование API
Для поиска пользователей используется GitHub API: GET https://api.github.com/users/{username}

## Примеры использования
1. Введите логин пользователя в поле поиска и нажмите «Поиск».
2. Просмотрите результаты.
3. Добавьте пользователя в избранное — он сохранится в файл favorites.json.
4. Избранные пользователи загружаются при запуске приложения.
```

- Убедитесь, что избранные сохраняются и загружаются корректно.
- Проверьте поведение при пустом поле поиска.
